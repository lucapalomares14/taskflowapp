TaskFlow es una aplicación móvil en desarrollo para la gestión y organización de tareas.

Tecnologías utilizadas:
. React Native
. Expo
. JavaScript

Estructura del proyecto:

taskflow-app/
├── src/
│   ├── assets/
│   ├── components/
│   ├── screens/
│   └── theme/
├── App.js
├── app.json
├── package.json
├── index.js
└── README.md

Instalación
. Clonar el repositorio.
. Instalar las dependencias:
. npm install

Iniciar el proyecto:
. npx expo start
. Escanear el código QR con Expo Go para abrir la aplicación.

Checkpoint 1: Estructura Base

La aplicación muestra una pantalla de bienvenida con el nombre TaskFlow y el mensaje "Estructura base lista".

Estado: Estructura base inicializada correctamente.
